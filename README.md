# news-image-20261124

A one-image summary of 24 November 2026's world news, built by an AI agent
pipeline on make.fun: Wayback Machine snapshots of ~20 news front pages are
curated into a news-sheet poster (`entry.png`), with curation notes in
`notes.md` and a reproducible builder in `main.py`.

Run the builder with:

```sh
python main.py
```

It verifies `entry.png` (PNG format, 1024×1024, ≤ 1 MiB) and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png`, printing a JSON receipt.
